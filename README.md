# 玉皇山公园 · 纯风景版路线图

余姚玉皇山公园亲子散步的照片路线图（**纯风景版**：仅收录无人风景照，16 张 · 11 个停留点）。

打开 `index.html` 即可离线查看：亮色天地图矢量底图，可切换卫星影像；橙色路线按拍摄顺序连线，数字图钉点击可看该处照片，右侧为照片时间轴。

## 快速开始

- 直接双击 `index.html`，或
- 本地起个静态服务：`python -m http.server 8080`，访问 `http://localhost:8080`

## 数据说明

- 照片定位：手机相机 EXIF（WGS-84），与天地图坐标系一致，无偏移换算
- 底图：天地图（© 天地图，瓦片令牌见 `index.html` 内 `TDT_TK`）
- 公园边界：高德官方 AOI 数据（已描绿），树下 GPS 漂移点已按边界内收修正并在页面注明
- 地图引擎：MapLibre GL JS（本地自托管）

## 版本

- **纯风景版（本仓库）**：16 张无人风景照 · 11 站，适合公开分享
- 有人有风景版：30 张全量 · 14 站，仅本地保留
